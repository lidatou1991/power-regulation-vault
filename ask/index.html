Regulatory Intelligence QA

不是通用聊天机器人。每个陈述显示证据层级、时间状态、来源和仍不确定的地方。Not a generic chatbot. Every statement preserves its trust layer, temporal status, provenance and uncertainty.

This is a prototype.

Finite local answer set · no live search · no model API · questions are not transmitted

02 / TRUST LAYERS

不是一个模糊的“AI 信心分数”

One answer can contain multiple evidence classes.

已验证 / VERIFIED

Human-reviewed formal knowledge.

待审核 / NEEDS REVIEW

Authoritative evidence collected; expert review pending.

未验证 / UNVERIFIED

External, historical or exploratory evidence.

行业观点

Professional interpretation—not law.

学术研究

Academic finding with scope limits.

实时信号

A sensor that must resolve to formal evidence.

03 / ARCHITECTURE

证据先于答案。

  1. Frontend
  2. QA Orchestrator
  3. Knowledge + Candidate Retrieval
  4. External Layer
  5. Answer Composer
  6. Trust / Provenance
  7. Research Gap Candidate

当前公开原型停留在经过清理的确定性数据集。未来外部检索仍不会直接成为 VERIFIED。
The public prototype uses a sanitized deterministic dataset. Future external retrieval will never become VERIFIED by retrieval alone.
