02 / TRUST LAYERS · NIVELES DE CONFIANZA

不是一个模糊的“AI 信心分数”

Una respuesta puede combinar distintas clases de evidencia.

已验证 / VERIFIED / VERIFICADO

Conocimiento formal revisado por una persona.

待审核 / NEEDS REVIEW / PENDIENTE DE REVISIÓN

Evidencia oficial preparada; falta la decisión experta.

未验证 / UNVERIFIED / NO VERIFICADO

No sustenta por sí sola una conclusión jurídica verificada.

行业观点 / VISIÓN DE LA INDUSTRIA

Interpretación profesional; no es derecho vigente.

学术研究 / EVIDENCIA ACADÉMICA

Hallazgo académico con alcance y límites explícitos.

实时信号 / SEÑAL

Indicio que debe contrastarse con evidencia formal.

03 / ARCHITECTURE

证据先于答案。

  1. Frontend
  2. QA Orchestrator
  3. Knowledge + Candidate Retrieval
  4. External Layer
  5. Answer Composer
  6. Trust / Provenance
  7. Research Gap Candidate

当前公开原型停留在经过清理的确定性数据集。未来外部检索仍不会直接成为 VERIFIED。
The public prototype uses a sanitized deterministic dataset. Future external retrieval will never become VERIFIED by retrieval alone.
