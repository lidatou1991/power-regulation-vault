# Publication Checklist

- [ ] authoritative source verified
- [ ] effective date verified
- [ ] superseding-law check completed
- [ ] enactment-chain check completed where relevant
- [ ] conflicting sources resolved or disclosed
- [ ] `verified_through` recorded
- [ ] CURRENT / HISTORICAL / TRANSITIONAL clearly distinguished
- [ ] executive summary matches evidence
- [ ] no unsupported legal interpretation presented as fact
- [ ] copyright/display restrictions reviewed
- [ ] human reviewer approval completed
- [ ] `publication_status` set appropriately

Completion supports a publication decision but does not itself publish a note. Record the reviewer and review date in the knowledge note.
